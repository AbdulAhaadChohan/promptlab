## Prompt

Please update the current `SPEC.md` file by incorporating the following detailed section updates to ensure 100% compliance with hackathon rules:

1. **Update Section 2.1 (CLI Flag Fix & Output Behavior)**:
   - Change all references of `--print` to `--report`.
   - Update flag description:
     `--report`: Optional flag to output a human-readable summary.
   - Stream Routing Rule:
     - If `--out report.json` is provided, the human-readable report generated by `--report` MUST be printed to `stderr`.
     - If `--out` is omitted, the raw JSON report is printed to `stdout`, and the `--report` summary (if requested) MUST go to `stderr` to prevent stdout corruption.

2. **Update Section 1 & Section 3.3 (Subprocess Model Invocation Contract)**:
   - Add explicit Subprocess Call Specification:
     All model calls must execute the target binary via subprocess using this exact argument structure:
     `python <model_binary> --prompt <prompt_file> --input <resolved_input> --temperature <temp> --max-tokens <max_tokens>`
   - Execution Safeguards:
     - Apply a strict **30-second timeout** per individual subprocess execution.
     - If the model binary exceeds 30 seconds, throws an unhandled exception, or returns a non-zero exit status, `promptlab` must abort and exit with **Exit Code 3** (Model Invocation Failure), outputting a one-line error to `stderr`.

3. **Update Section 3.4 (Edge Cases in Suite Parsing)**:
   - **Empty Suite (`"cases": []`)**: Must be accepted as a valid suite. `promptlab` runs without error, generates a report with zero total metrics (`cases: 0`, `passed: 0`, `failed: 0`), and exits with **Exit Code 0**.
   - **Empty Assertions (`"assert": []`)**: If a case defines no assertions, its evaluation depends solely on successful model execution. If the model invocation completes with exit code 0, the case is marked as `pass` (`pass_rate: 1.0`).

4. **Update Section 5.1 (Matches Assertion - Invalid Regex Handling)**:
   - Under `matches` assertion: If the provided `pattern` is an invalid or unparseable regular expression (e.g., raises `re.error`), `promptlab` must fail immediately during suite validation/preprocessing before executing any model subprocess calls. It must print a single-line error to `stderr` and terminate with **Exit Code 1** (Bad Usage / Malformed Input).

5. **Update Section 2.2 & 7.5 (Comparison JSON Output Schema)**:
   - Define the exact JSON schema generated by `promptlab compare`:
     ```json
     {
       "baseline_hash": "a19f40cc21b8",
       "candidate_hash": "b20e51dd32c9",
       "delta": {
         "pass_rate_change": 0.35,
         "tokens_in_change_pct": -4.2,
         "tokens_out_change_pct": 2.1,
         "wall_ms_change_pct": -10.5
       },
       "regressions": ["case_002"],
       "improvements": ["case_001", "case_004"],
       "unchanged": ["case_003"]
     }
     ```
   - Rules:
     - `pass_rate_change`: Candidate average pass rate minus baseline average pass rate.
     - `regressions`: Cases where candidate `pass_rate` < baseline `pass_rate`.
     - `improvements`: Cases where candidate `pass_rate` > baseline `pass_rate`.
     - `unchanged`: Cases with equal `pass_rate`.
